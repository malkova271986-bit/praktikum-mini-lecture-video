# Практикум: серия мини-лекций с героем

Серия коротких (4–5 минут) видеолекций к учебному практикуму Е. В. Бэкман. Лекции ведёт герой практикума — мальчик в голографической толстовке с двумя летающими роботами. Каждое видео собрано по презентации лекции и озвучено в ElevenLabs.

## Лекции

| № | Тема | Длительность | Папка |
|---|------|--------------|-------|
| 1 | Цифровизация и цифровые технологии в образовании | 3:50 | `lectures/01-tsifrovizatsiya` |
| 2 | ИКТ в образовании, социология интернета и теория поколений | 4:40 | `lectures/02-ikt-i-pokoleniya` |
| 3 | Дизайн ЭОР: от педагогических принципов до игровых механик (завершающая) | 4:20 | `lectures/03-dizain-eor` |

В папке каждой лекции:

- `*_мини-лекция.mp4` — готовое видео (1920×1080, субтитры вшиты);
- `Текст_для_озвучки*.txt` — текст, который вставлялся в ElevenLabs;
- `YouTube_описание*.txt` — название, описание с главами, теги;
- `YouTube_обложка*.jpg` — значок видео 1280×720;
- `*_субтитры.srt` — субтитры для загрузки на YouTube;
- `index.html` — исходник анимации (открывается в браузере; `render(t)` показывает кадр в момент *t*);
- `subs.json` / `voice.json` — тексты субтитров и озвучки по сценам.

## Как сделать следующую лекцию в этом стиле

- **`skill/SKILL.md`** — навык для Claude: анализ презентации → текст для озвучки → анимация → синхронизация с озвучкой → MP4 и комплект для YouTube. Пошаговое описание процесса есть и в самом навыке.
- **`tools/`** — скрипты, на которые опирается навык: шаблон композиции, вырезка героя, синхронизация с голосом, музыка, рендер.
- **`assets/hero/`** — исходные изображения героя и подготовленные спрайты (анфас, профиль, роботы, окно-голограмма).

Настройки YouTube для практикума: «Доступ по ссылке», «Не для детей», категория «Образование».
